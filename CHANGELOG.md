# Changelog

## 0.11 (draft)

Initial draft, in two documents: Troupe Format and Troupe Play.

Before release, the draft was cut down: sessions are snapshots with one message per line, a chronicle is one JSON document, and `"*"` map keys are ordered by code point. Callable events, audio parts, media provenance, `appearance`, `voice` and `talkativeness` moved to draft extensions or `ext`, and the YAML source form was dropped. Patterns, the authoring brief and the Character Card mappings moved into guides.
