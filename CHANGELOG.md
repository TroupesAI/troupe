# Changelog

## 0.11 (draft)

Initial draft, in two documents: Troupe Format and Troupe Play.

Before release, the draft was cut down: sessions are snapshots with one message per line, a chronicle is one JSON document and a session continues at most one, `"*"` map keys are ordered by code point, and `mode` is `characters` or `narrator`. Callable events, audio, reasoning and tool parts, media provenance, `appearance`, `voice` and `talkativeness` moved to draft extensions or `ext`, and the YAML source form was dropped. Patterns, the authoring brief and the Character Card mappings moved into guides.
